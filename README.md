# HingeNexus

HingeNexus enables Real-Time, High-Performance data processing and aggregation, providing a centralized Service for Real-Time Decision Making.

HingeNexus is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- rust

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/HingeNexus.git`
2. `cd HingeNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
